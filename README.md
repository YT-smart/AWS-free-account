# AWS Lightsail 云电脑 · 自动部署 Skill

一个让 AI 帮你全自动搞定 AWS 云服务器的 Skill。

你只需要提供邮箱、手机号，选一个地区和配置，剩下的注册、填表、买机器、配网络，全部交给 AI。

部署完成后，你会收到一台 Windows 云电脑的完整连接信息，打开远程桌面就能用。

---

## 这是什么

这是一份结构化的 AI 指令（Skill），用于指导具有浏览器操控能力的 AI（如 [Dola](https://dola.com/) 的云电脑）自动完成以下流程：

1. **注册 AWS 账号**（在云浏览器中完成，绕开本地环境检测）
2. **创建 Lightsail Windows 实例**（选配置、选地区、一键创建）
3. **设置静态 IP**（固定服务器地址，不会每次重启都变）
4. **挂载 32GB 数据盘**（给你一块额外的 D 盘，别把东西全堆 C 盘）
5. **获取连接凭证**（IP、用户名、密码，打包发给你）

全程只有一个地方需要你动手：**去邮箱拿验证码，发给 AI**。其他全自动。

## 你能得到什么

部署完成后，AI 会把以下信息一次性发给你：

```
📋 AWS 账号（邮箱 + 密码）
🖥️ 服务器连接信息（IP + 用户名 + 密码）
💰 费用信息（赠送额度 + 月费 + 预估可用时间）
📌 连接教程（Windows / Mac / 手机）
```

**关于费用：**
- AWS 新用户注册送 **$100**，做完新手任务最多再领 **$100**
- 选 $22/月 的配置，$200 额度大约能用 **6 个月**
- 服务器这一块的钱，前面半年基本不用你自己掏

## 怎么用

### 前提

你需要一个能操控浏览器的 AI，比如 [Dola](https://dola.com/) 的云电脑功能。

### 步骤

1. 把仓库地址发给 AI，告诉它安装这个 Skill：

```
帮我安装：https://github.com/YT-smart/aws-lightsail-claude.git
```

2. AI 会问你要 4 样东西：

| 必填 | 说明 |
| --- | --- |
| 邮箱 | 能收验证码的邮箱（QQ / Gmail 都行） |
| 手机号 | 含区号，如 +86 138xxxx |
| 服务器地区 | 悉尼（默认）/ 美国 / 日本 |
| 配置 | $22/月 或 $44/月 |

3. AI 开始自动操作，中途只会暂停一次让你提供邮箱验证码
4. 全部完成后，你会收到服务器的 IP、用户名、密码和连接教程
5. 打开远程桌面，连上去，就是一台你自己的海外 Windows 电脑

## 适合谁

- 想稳定使用 Claude / Claude Code，需要一台干净的海外环境
- 不想折腾服务器配置，希望 AI 帮你一键搞定
- 想用 AWS 的免费额度，省下前几个月的服务器费用

## 注意事项

- 本 Skill 只负责部署服务器，**不包含 Claude 的安装和会员开通**
- AWS 的免费额度有有效期（通常 6 个月），额度用完后会按月计费
- 如果注册过程中被要求绑定银行卡，AI 会暂停并告知你，不会强行操作
- 服务器密码和 AWS 密码是两个不同的东西，请妥善保管
