# 交付信息模板

部署完成后，AI 按照以下模板将所有信息一次性发送给用户。

**使用规则：**
- 方括号 `[...]` 中的内容替换为实际值
- 如果用户没有加硬盘，删除硬盘相关的行
- 如果有任何步骤未完成或异常，在末尾的注意事项中说明

---

```
✅ 你的 AWS 云电脑已经部署完成！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 AWS 账号
   登录地址：https://signin.aws.amazon.com/signup?request_type=builderId
   邮    箱：[邮箱地址]
   密    码：[AWS 账号密码]

🖥️ 远程连接
   公网 IP ：[静态 IP 地址]
   用户名  ：Administrator
   密    码：[Windows 服务器密码]

📍 服务器信息
   地    区：[服务器地区，如 Sydney / US East]
   系    统：Windows Server 2022
   配    置：[2 vCPU / XGB 内存 / XXGB 系统盘]
   附加硬盘：[32GB / 无]

💰 费用
   当前额度：$[XXX]（注册赠送 $100 + 新手任务 $[XX]）
   新手任务：[已完成 X/5]
   到期时间：[XXXX-XX-XX]
   月费合计：$[XX]（实例 $XX + 硬盘 $XX）
   预估可用：约 [X] 个月

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔌 怎么连接？

Windows 电脑：
  1. 按 Win + R → 输入 mstsc → 回车
  2.「计算机」填入公网 IP
  3. 点连接 → 更多选项 → 使用其他账户
  4. 用户名：Administrator
  5. 密码：上面的服务器密码
  6. 弹出证书提示，点「是」

Mac 电脑：
  1. App Store 下载 Microsoft Remote Desktop
  2. 添加电脑 → 填入公网 IP、用户名、密码
  3. 双击连接

手机（iOS / Android）：
  1. 下载 RD Client（微软远程桌面）
  2. 添加电脑 → 填入公网 IP、用户名、密码
  3. 点连接

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 首次使用注意

1. 如果加了硬盘，第一次进入需要初始化：
   按 Win + R → 输入 diskmgmt.msc → 回车
   → 新磁盘右键「联机」→「初始化」→ 右键未分配区域
   →「新建简单卷」→ 一路下一步 → 选盘符 D → 完成
   之后就能在「此电脑」看到 D 盘了

2. 软件和文件都放 D 盘，别堆 C 盘

3. 用完直接关远程桌面窗口就行
   不要在服务器里点「关机」，否则程序会停

4. AWS 密码和服务器密码是两个东西，都要存好

5. 已帮你设置零花费预算提醒，有超出额度的花费会发邮件通知你

6. 免费计划满 6 个月或额度用完会自动关闭账号
   到期前记得把重要文件备份到自己电脑
```

## 可选：新手任务未全部完成时的提醒

如果第 4.5 步有任务未完成（额度未到 $200），在交付信息后附加：

```
💡 还有 $[XX] 没领到

未完成的任务：[任务名称]（原因：[原因]）
你可以稍后让我登录账号补做，或者在 AWS 控制台首页的 Explore AWS 里手动完成。
```
